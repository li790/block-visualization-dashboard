# 运营成本管理看板 v5.3

## 更新说明

### 重要变更 (v5.3)

#### 1. 移除文件保存功能
- **不再支持**：将上传的文件保存到 `data` 目录
- **原因**：避免多用户间的数据污染和冲突
- **优势**：确保数据安全，防止恶意文件上传

#### 2. 内存缓存系统
- **替换**：文件系统缓存 → 纯内存缓存
- **技术**：使用 Streamlit `session_state` 进行缓存管理
- **优势**：
  - 避免多用户间的缓存冲突
  - 提升性能，减少磁盘I/O
  - 会话结束后自动清理，避免内存泄漏
  - 24小时缓存过期机制

#### 3. 简化项目结构
- **删除目录**：`output/`、`icon/` 目录已移除
- **页面图标**：使用emoji图标替代本地图片文件
- **架构优化**：完全基于内存的数据处理流程
- **功能精简**：移除文件管理功能，专注于数据分析

## 功能特性

### 核心功能
- 📊 **成本分析**：支持多项目成本数据分析和可视化
- 🚀 **高性能**：内存缓存机制，大幅提升数据处理速度
- 🔒 **数据安全**：文件只在内存中处理，不写入磁盘
- 👥 **多用户支持**：每个用户会话独立，避免数据冲突

### 数据处理
- 支持 Excel 文件上传和处理
- 自动识别主要费项和三级费项表格
- 智能费项分类和异常检测
- 多月份数据对比分析
- 多项目汇总数据分类导出功能

### 可视化图表
- 成本结构饼图
- 月度趋势折线图
- 费项分布柱状图
- 异常数据热力图

## 技术架构

### 缓存系统
```python
# 内存缓存管理器
class MemoryCacheManager:
    - 使用 Streamlit session_state 存储缓存
    - 支持文件数据和分析结果缓存
    - 24小时自动过期机制
    - 会话结束后自动清理
```

### 数据处理流程
1. **文件上传** → 内存存储
2. **数据提取** → Excel表格解析
3. **缓存检查** → 内存缓存查询
4. **数据分析** → 成本计算和分类
5. **结果展示** → 图表和表格输出

## 部署说明

### 服务器部署
- **多用户支持**：每个用户会话完全独立
- **内存管理**：缓存自动清理，避免内存泄漏
- **性能优化**：无磁盘I/O，响应速度更快
- **资源节省**：无需维护缓存目录和图标文件

### 环境要求
- Python 3.7+
- Streamlit 1.0+
- pandas, numpy, plotly 等依赖包

## 使用说明

### 基本操作
1. 上传 Excel 文件（支持多文件）
2. 选择是否包含自有人工成本
3. 选择要分析的文件
4. 设置分析月份
5. 查看分析结果和图表
6. 下载多项目汇总数据（包含12个分类工作表）

### 注意事项
- 文件只在内存中处理，不会保存到服务器
- 缓存数据在会话结束后自动清理
- 支持大文件处理，建议单文件不超过100MB
- 页面图标使用emoji，无需额外图片文件
